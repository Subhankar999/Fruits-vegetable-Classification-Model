# Fruit & Vegetable Classification

## 📌 Project Overview

Fruit & Vegetable Classification is a Deep Learning web application that classifies different types of fruits and vegetables from uploaded images.

The project uses a trained **PyTorch CNN model** with image preprocessing using resizing, tensor conversion, and normalization. A **FastAPI backend** handles image uploads and model predictions, while a responsive **HTML, CSS, and JavaScript frontend** provides an easy-to-use interface for users.

The model is trained to classify **77 different types of fruits and vegetables**. The application displays the predicted fruit or vegetable along with the model's confidence score.

The application is deployed using **Vercel** for the frontend and **Render** for the backend.
